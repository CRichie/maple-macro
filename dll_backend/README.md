# DLL 后端实验状态

此目录是尚未接入主程序的实验性代码。不要用于游戏操作。

- rs01.dll 为用户提供组件的副本；rs01.tlb 是此前分析时提取的类型库副本。
- backend.manifest 和 worker.ps1 用于 32 位免注册 COM 加载实验。
- 本机已验证 COM 实例可创建，但 BindWindowEx 风格的绑定调用在测试窗口触发 0xC0000005（访问冲突）。未绑定时 KeyDown/KeyUp 返回成功，但测试窗口未收到按键。
- 原因尚未确定，可能涉及调用约定、接口参数、组件依赖或运行环境；不能将推测当作结论。
- 未修改宏主程序；继续使用现有 keybd_event 方式。

后续排查：使用类型库声明的 Iqdghas 接口槽位直接调用，与 IDispatch 调用一样，在 Bind 调用中出现 0xC0000005；传入有效测试窗口或空句柄均复现。Windows 应用程序事件记录的故障模块为 unknown，不能据此定位到具体函数。独立窗口并未收到按键。REA 对解包 DLL 的绑定函数进一步分析超时，原因仍未确定。worker_vtable.ps1 是第二种实验实现，不接入主程序。
