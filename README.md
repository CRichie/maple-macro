# Maple Macro

Windows 本地键盘宏，提供网页配置、四个光圈之间的定时技能循环、巡回和按键记录测试。

## 运行

需要 Windows 和支持 Tkinter 的 Python 3。无需安装第三方 Python 包。

```powershell
python macro_web.py
```

程序会自动打开仅监听 `127.0.0.1` 的配置页面，终端也会显示页面地址。请通过服务提供的地址访问，不要直接打开 HTML 文件。保存配置后将角色放在光圈 1；按 F8 启动、F9 停止。点击页面的“打开按键测试页面”可在测试页面处于前台时记录收到的按键事件。

## 行为与限制

- 光圈移动固定按上键；技能顺序、间隔和随机附加按键可在页面配置。随机动作默认不包括左右方向键。
- 每轮补放之间安排一次巡回：经过另外三个位置，各停留一段时间，再回到起点。巡回期间暂停攻击和其他随机按键；周期不足时跳过巡回。
- 按键发送到当前焦点窗口；程序不会识别角色位置或测谎提示音。使用 F9 停止后再切换窗口。
- 输入通过 Windows `keybd_event` 合成，不保证游戏兼容或避免反外挂检测。实际效果需自行在测试环境确认。
- 配置、运行日志和缓存只保存在本机，不纳入版本控制。请勿分享日志中的本地访问令牌。

## 文件

- `macro.py`：按键、计时与循环逻辑，以及早期的桌面配置界面。
- `macro_web.py`、`macro.html`：本地网页服务和配置界面。
- `macro_test.html`：前台按键事件和时间间隔记录页面。
- `dll_backend/`：未完成的 DLL 后端实验，不能用于正常操作；不包含第三方组件。
